###### KNOWLEDGE BASE

### Release Notes v1.9.10

[Fluent Bit](https://fluentbit.io) is a Fast and Lightweight Data Processor and Forwarder for Linux, BSD and OSX. We are proud to announce the availability of **Fluent Bit v1.9.10**.

> **Note:** this is a source-only maintenance release; no binary packages are published.

#### Changes

 - __Core__
   - core: add minimal synchronous scheduler support
   - parser: fix time zone offsets being dropped on Windows (#6368)

 - __Plugins__
   - [S3 (Output)](https://docs.fluentbit.io/manual/1.9/pipeline/outputs/s3/)
      - Add `store_dir_limit_size` option to cap local disk usage
   - [CloudWatch Logs (Output)](https://docs.fluentbit.io/manual/1.9/pipeline/outputs/cloudwatch/)
      - Enable synchronous scheduler and async networking
   - [Elasticsearch (Output)](https://docs.fluentbit.io/manual/1.9/pipeline/outputs/elasticsearch/)
      - Fix bulk buffer overrun
   - [Datadog (Output)](https://docs.fluentbit.io/manual/1.9/pipeline/outputs/datadog/)
      - Fix and add error handling for all `flb_sds` calls (#5929)
   - [Forward (Output)](https://docs.fluentbit.io/manual/1.9/pipeline/outputs/forward/)
      - Release buffer when no connection available and `time_as_integer` is true (#6082)
   - [ECS Filter (Filter)](https://docs.fluentbit.io/manual/1.9/pipeline/filters/)
      - New filter plugin for AWS ECS task metadata enrichment (#5898)
   - [TCP (Input)](https://docs.fluentbit.io/manual/1.9/pipeline/inputs/tcp/)
      - Add user-friendly warning when skipping records (#6061)
   - [Tail (Input)](https://docs.fluentbit.io/manual/1.9/pipeline/inputs/tail/)
      - Fix multiline + `Path_Key` emitting empty logs when both options are active
   - [Multiline (Core)](https://docs.fluentbit.io/manual/1.9/pipeline/filters/multiline-stacktrace/)
      - Do not permanently set multiline group time to the first log time (#6381)
