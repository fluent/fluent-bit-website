###### KNOWLEDGE BASE

## Release Notes v4.2.4

Fluent Bit is a Fast and Lightweight Data Processor and Forwarder for Linux,
BSD, Windows and macOS. We are proud to announce the availability of Fluent
Bit v4.2.4.

Below is a detailed list of changes included in this release...


### What's new ?

Fluent Bit v4.2.4 is a maintenance release focused on stability and correctness.
It fixes Kubernetes filter prefix handling, multiline metadata propagation,
log-to-metrics memory management, OTEL scope key leaks in the content modifier
processor, HTTP/2 request body size enforcement, and Avro format specification
errors. The engine metric accounting for post-processors is also corrected.

<br>

#### Core

<br>

- multiline: propagate metadata even on parse exceptions
- processor_content_modifier: fix OTEL scope autogenerated key memory leak
- http_server: enforce `buffer_max_size` limit for HTTP/2 request bodies
- avro: fix specification errors in Avro format handling for Kafka output
- engine: use effective post-processor counts when computing output metrics
- dockerfiles: install minimum required components only

### Libraries

- monkey: upgrade bundled library to v1.8.8

### Plugins

<br>

- **[Kubernetes (Filter)](https://docs.fluentbit.io/manual/pipeline/filters/kubernetes)**
  - fix accidentally removed character in namespace prefix handling
- **[Log to Metrics (Filter)](https://docs.fluentbit.io/manual/pipeline/filters/log_to_metrics)**
  - use pre-allocated memory slots for label storage to avoid unsafe reallocation
