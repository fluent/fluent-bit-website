###### KNOWLEDGE BASE

## Release Notes v4.2.3.1

Fluent Bit is a Fast and Lightweight Data Processor and Forwarder for Linux,
BSD, Windows and macOS. We are proud to announce the availability of Fluent
Bit v4.2.3.1.

Below is a detailed list of changes included in this release...


### What's new ?

Fluent Bit v4.2.3.1 is a targeted hotfix release that corrects the Docker
image build to install only the minimum required components.

<br>

#### Core

<br>

- dockerfiles: install minimum components only, avoiding `includeRecommended`
  packages to reduce image size and attack surface

### Libraries

- No bundled library upgrades in this release.

### Plugins

- No plugin changes in this release.
