###### KNOWLEDGE BASE

## Release Notes v4.0.13

Fluent Bit is a Fast and Lightweight Data Processor and Forwarder for Linux, BSD, Windows and macOS. We are proud to announce the availability of Fluent Bit v4.0.13.

Below is a detailed list of changes included in this release...


### What's new ?

<br>

#### Core

<br>

- storage: fix heap corruption in chunk sort parser ([PR #11022](https://github.com/fluent/fluent-bit/pull/11022))

### Plugins

<br>

- **[Calyptia Fleet (Input)](https://docs.fluentbit.io/manual/pipeline/inputs/calyptia_fleet)**
  - load configuration on initial startup ([PR #10997](https://github.com/fluent/fluent-bit/pull/10997))
- **[Forward (Input)](https://docs.fluentbit.io/manual/pipeline/inputs/forward)**
  - fix handshaking sequence in the Forward protocol ([PR #11029](https://github.com/fluent/fluent-bit/pull/11029))
