###### KNOWLEDGE BASE

## Release Notes v4.0.14

Fluent Bit is a Fast and Lightweight Data Processor and Forwarder for Linux, BSD, Windows and macOS. We are proud to announce the availability of Fluent Bit v4.0.14.

Below is a detailed list of changes included in this release...


### What's new ?

<br>

#### Core

<br>

- engine: fix memory leaks in `parse_string_map_to_list` error paths ([PR #10944](https://github.com/fluent/fluent-bit/pull/10944))
- help: add proper spacing for outputs and processors in schema generation ([PR #11021](https://github.com/fluent/fluent-bit/pull/11021))
- fstore: add safety check on file deletion ([PR #11058](https://github.com/fluent/fluent-bit/pull/11058))
- wasm: plug heap memory leaks in Wasm plugin execution ([PR #11118](https://github.com/fluent/fluent-bit/pull/11118))

### Plugins

<br>

- **[Tail (Input)](https://docs.fluentbit.io/manual/pipeline/inputs/tail)**
  - fix `last_processed_bytes` calculation ([PR #11048](https://github.com/fluent/fluent-bit/pull/11048))
- **[Forward (Input)](https://docs.fluentbit.io/manual/pipeline/inputs/forward)**
  - fix connection release on pause causing memory corruption ([PR #11182](https://github.com/fluent/fluent-bit/pull/11182))
  - fix segfault and double-free in trace path handling ([PR #11266](https://github.com/fluent/fluent-bit/pull/11266))
- **[OpenTelemetry (Input)](https://docs.fluentbit.io/manual/pipeline/inputs/opentelemetry)**
  - add five missing configuration option descriptions ([PR #11195](https://github.com/fluent/fluent-bit/pull/11195))
- **[Windows Event Log (Input)](https://docs.fluentbit.io/manual/pipeline/inputs/windows-event-log-winevtlog)**
  - fix time offset glitches during DST/STD clock switches ([PR #11298](https://github.com/fluent/fluent-bit/pull/11298))
- **[Flow Counter (Output)](https://docs.fluentbit.io/manual/pipeline/outputs/flowcounter)**
  - fix incorrect bytes calculation ([PR #11260](https://github.com/fluent/fluent-bit/pull/11260))
