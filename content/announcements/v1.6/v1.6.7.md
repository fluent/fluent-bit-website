###### KNOWLEDGE BASE

### Release Notes v1.6.7

[Fluent Bit](https://fluentbit.io/) is a Fast and Lightweight Data Forwarder for Linux, BSD and OSX. We are proud to announce the availability of **Fluent Bit v1.6.7.**

For people upgrading from previous versions you **must read** the Upgrading Notes section of our documentation:

[https://docs.fluentbit.io/manual/1.6/installation/upgrade_notes](https://docs.fluentbit.io/manual/1.6/installation/upgrade_notes)

#### Changes

[Fluent Bit](https://fluentbit.io) v1.6.7 is the minor release on 1.6 that comes with the following changes:


**Core**

* signv4: fix write heap-overflow discovered via oss-fuzz (#27710)
* record_accessor: fix multiple NULL dereferences (oss-fuzz #27234)
* pack/gelf: fix stack buffer overflow on temp variable (oss-fuzz #26237)
* json parser: fix null-dereference (oss-fuzz #27764)
* socket: fix error socket status check (#2826 #2827)
* io: use `flb_socket_error()` for socket validation
* parser: add new option `Time_Strict` (#2813)
* input_chunk: update tag value extraction for backoff logs (#2806)
* input: fix socket error during shutdown on Windows (#2812)


**Plugins**

* [GELF (Output)](https://docs.fluentbit.io/manual/1.6/pipeline/outputs/gelf/)
  * Accept all possible severity level values (#2257)
* [BigQuery (Output)](https://docs.fluentbit.io/manual/1.6/pipeline/outputs/bigquery/)
  * Fix URL construction discarding the last character (#2731)
* [HTTP (Output)](https://docs.fluentbit.io/manual/1.6/pipeline/outputs/http/)
  * Suppress proxy debug output when proxy is not configured
* [AWS (Core)](https://docs.fluentbit.io/manual/1.6/pipeline/outputs/)
  * ECS credential provider takes priority before EC2 in standard chain
