###### KNOWLEDGE BASE

## Release Notes v4.1.2

Fluent Bit is a Fast and Lightweight Data Processor and Forwarder for Linux, BSD, Windows and macOS. We are proud to announce the availability of Fluent Bit v4.1.2.

Below is a detailed list of changes included in this release...


### What's new ?

<br>

#### Core

<br>

- reload: fix race condition between watchdog startup and async cancellation setting ([PR #11012](https://github.com/fluent/fluent-bit/pull/11012))
- storage: fix heap corruption in chunk sort parser ([PR #11017](https://github.com/fluent/fluent-bit/pull/11017))
- help: add proper spacing for outputs and processors in schema generation ([PR #11066](https://github.com/fluent/fluent-bit/pull/11066))
- fstore: add safety check on file deletion ([PR #11061](https://github.com/fluent/fluent-bit/pull/11061))
- wasm: plug heap memory leaks in Wasm plugin execution ([PR #11119](https://github.com/fluent/fluent-bit/pull/11119))

### Plugins

<br>

- **[Calyptia Fleet (Input)](https://docs.fluentbit.io/manual/pipeline/inputs/calyptia_fleet)**
  - add support for `net.*` properties on the upstream connection ([PR #10998](https://github.com/fluent/fluent-bit/pull/10998))
- **[Forward (Input)](https://docs.fluentbit.io/manual/pipeline/inputs/forward)**
  - fix username parsing during handshake ([PR #11026](https://github.com/fluent/fluent-bit/pull/11026))
  - fix incorrect user authentication sequence ([PR #11028](https://github.com/fluent/fluent-bit/pull/11028))
  - fix connection release on pause causing memory corruption ([PR #11179](https://github.com/fluent/fluent-bit/pull/11179))
  - fix segfault and double-free in trace path handling ([PR #11267](https://github.com/fluent/fluent-bit/pull/11267))
- **[OpenTelemetry (Input)](https://docs.fluentbit.io/manual/pipeline/inputs/opentelemetry)**
  - add five missing configuration option descriptions ([PR #11194](https://github.com/fluent/fluent-bit/pull/11194))
- **[S3 (Output)](https://docs.fluentbit.io/manual/pipeline/outputs/s3)**
  - add NULL check to prevent segfault during dry-run mode ([PR #11123](https://github.com/fluent/fluent-bit/pull/11123))
- **[Flow Counter (Output)](https://docs.fluentbit.io/manual/pipeline/outputs/flowcounter)**
  - fix incorrect bytes calculation ([PR #11261](https://github.com/fluent/fluent-bit/pull/11261))
