###### KNOWLEDGE BASE

## Release Notes v5.2.1

[Fluent Bit](https://fluentbit.io) is a fast and lightweight telemetry agent for Linux, BSD, macOS, and Windows. **Fluent Bit v5.2.1** is now available.

This release makes shared YAML configurations easier to maintain, expands the experimental browser SDK to handle OpenTelemetry metrics and traces, and improves delivery during backpressure and restarts.

### What's new ?

<br>

#### Reusable YAML configuration

Define shared settings under a top-level `defaults` mapping and reuse them across included files with YAML anchors, aliases, and explicit mapping merges. Individual pipelines can override inherited values locally. YAML errors now report where the problem occurs in the configuration. [YAML composition guide](https://github.com/fluent/fluent-bit/blob/v5.2.1/docs/configuration/yaml-composition.md)

#### OpenTelemetry and routing in the experimental browser SDK

The browser SDK now accepts OTLP JSON metrics and traces alongside logs. It can also evaluate routing conditions, show the resolved pipeline topology, and trace where a record goes, making it easier to debug pipeline behavior in the browser.

### Core

<br>

- **CRI parsing.** Add a native `cri` parser format and use it for the built-in CRI multiline parser to reduce parsing overhead for container logs.
- **Log processing.** Skip unnecessary group normalization for ordinary, ungrouped log batches.
- **Delivery and reload.** Account for throttled output routes when applying input backpressure and preserve shutdown failures when a pipeline is reloaded.
- **Networking and TLS.** Fix loading YAML upstream groups for high-availability configurations, verify TLS for AWS container credential endpoints, and improve Windows certificate trust recovery. [Windows TLS behavior](https://github.com/fluent/fluent-bit/blob/v5.2.1/docs/windows-tls.md)

### Libraries

<br>

- Fix a 64-bit heap relocation issue in the bundled WebAssembly Micro Runtime (WAMR) on Windows.

### Plugins

<br>

#### Inputs

- **MQTT.** Complete the QoS 2 handshake and respond correctly to subscription and unsubscription requests.
- **Forward.** Improve validation of compressed input batches.
- **Blob.** Fix file ingestion when no tracking database is configured.

#### Filters

- **Kubernetes.** Preserve metadata enrichment when a bearer token returned by a command ends with a line break.

#### Outputs

- **Google Cloud Storage.** Configure the record timestamp field and its format with `json_date_key` and `json_date_format`. The default remains an ISO 8601 timestamp in the `date` field.
- **Amazon S3.** Preserve upload cooldowns and retry state when recovering buffered uploads after a restart.
- **Kafka.** Make dynamic topic routing more reliable when multiple output workers are active.
- **File.** Add opt-in support for absolute paths in dynamically resolved Windows output filenames.

#### File handling

Tail, Blob, Calyptia Fleet, File, Amazon S3, and Azure Blob gain opt-in file path containment controls.

### Container images

<br>

Maintained release images can be rebuilt with base image fixes while keeping the same Fluent Bit version. Pull the version tag to pick up the latest rebuild, or use a dated tag or image digest to pin a specific build. [Container image index](https://github.com/fluent/fluent-bit/wiki/Container-Images)
