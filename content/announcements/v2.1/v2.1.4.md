###### KNOWLEDGE BASE

### Release Notes v2.1.4

[Fluent Bit](https://fluentbit.io) is a Fast and Lightweight Data Processor and Forwarder for Linux,
BSD and OSX. We are proud to announce the availability of **Fluent Bit v2.1.4**.

#### Changes

 - __Core__
   - tls: trim trailing dots from `tcp_host` and `proxied_host` for TLS vhost matching
   - multiline: use the appropriate scheduler to prevent sync/async race conditions
   - processor: fix cleanup and initialization ordering in the processor loop
   - processor: add limited concurrency support for threaded pipelines
   - processor: implement inline re-ingestion for processor chains
   - compression: add buffer adjust step to correctly compute available size
   - reload: prevent hot-reload intervals that are too short to be safe
   - in_emitter: add automatic threading detection workaround

 - __Libs__
   - monkey: upgrade bundled library to commit `13a4ccd3`

 - __Plugins__
   - [OpenTelemetry (Output)](https://docs.fluentbit.io/manual/2.1/pipeline/outputs/opentelemetry/)
      - Fix memory leak in output path
      - Flush multiple traces from a single chunk correctly
   - [Node Exporter Metrics (Input)](https://docs.fluentbit.io/manual/2.1/pipeline/inputs/node-exporter-metrics/)
      - Prevent duplicate sysfs path entries when collecting metrics
   - [Tail (Input)](https://docs.fluentbit.io/manual/2.1/pipeline/inputs/tail/)
      - Fix teardown and memory initialization on plugin shutdown
   - [Lua (Filter)](https://docs.fluentbit.io/manual/2.1/pipeline/filters/lua/)
      - Remove unused variables to clean up compilation warnings
