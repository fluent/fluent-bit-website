###### KNOWLEDGE BASE

### Release Notes v2.0.14

[Fluent Bit](https://fluentbit.io) is a Fast and Lightweight Data Processor and Forwarder for Linux,
BSD and OSX. We are proud to announce the availability of **Fluent Bit v2.0.14**.

#### Changes

 - __Core__
   - multiline: use the appropriate scheduler to avoid race conditions between the synchronous and asynchronous paths

 - __Plugins__
   - [Tail (Input)](https://docs.fluentbit.io/manual/2.0/pipeline/inputs/tail/)
      - Fix cleanup and initialization ordering in the pending collector
