###### KNOWLEDGE BASE

### Release Notes v2.0.13

[Fluent Bit](https://fluentbit.io) is a Fast and Lightweight Data Processor and Forwarder for Linux,
BSD and OSX. We are proud to announce the availability of **Fluent Bit v2.0.13**.

#### Changes

 - __Core__
   - tls: trim trailing dots from `vhost` to avoid TLS SNI mismatches

 - __Libs__
   - ctraces: upgrade to v0.3.1

 - __Plugins__
   - [Wasm (Filter)](https://docs.fluentbit.io/manual/2.0/pipeline/filters/wasm/)
      - Skip log emission on NULL or empty WASM return value
   - [Elasticsearch (Input)](https://docs.fluentbit.io/manual/2.0/pipeline/inputs/elasticsearch/)
      - Use the plugin-provided tag when routing records
      - Release buffer on error path to fix memory leak
   - [BigQuery (Output)](https://docs.fluentbit.io/manual/2.0/pipeline/outputs/bigquery/)
      - Initialize `sig_len` to prevent use of uninitialized value
   - [OpenTelemetry (Input)](https://docs.fluentbit.io/manual/2.0/pipeline/inputs/opentelemetry/)
      - Fix record structure for correct downstream processing
   - [OpenTelemetry (Output)](https://docs.fluentbit.io/manual/2.0/pipeline/outputs/opentelemetry/)
      - Fix error handling for failed msgpack decoding
      - Fix memory leak in output path
      - Flush multiple traces from a single chunk correctly
   - [Stackdriver (Output)](https://docs.fluentbit.io/manual/2.0/pipeline/outputs/stackdriver/)
      - Process `spanId` as a special field in log entries
   - [HTTP (Input)](https://docs.fluentbit.io/manual/2.0/pipeline/inputs/http/)
      - Fix parser memory reinitialization to prevent stale state
   - [Node Exporter Metrics (Input)](https://docs.fluentbit.io/manual/2.0/pipeline/inputs/node-exporter-metrics/)
      - Prevent duplicate sysfs path entries when collecting metrics
